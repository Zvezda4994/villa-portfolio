# The books with real titles on the library's eye-level shelves.
# blender/villa/library.py reads this when the scene is built. After editing it,
# rebuild: npm run scene, then npm run bake:draft and npm run export.
#
# Books go in groups, in shelf order: the upper eye-level shelf first, left to right,
# then the one below it. Each group starts with two lines, then one title per line:
#   author: the name printed on the spine (leave it empty for none)
#   spine:  how the spines look, one of the styles below
# Blank lines and lines starting with # are skipped.
#
# Spine styles:
#   oxblood cloth   gold serif lettering on dark red cloth, tall hardbacks
#   black serif     off-white serif lettering on black, hardbacks
#   navy            white lettering on navy
#   cream           black lettering on cream
#   white           black lettering on white
#   grey            white lettering on slate grey
#   olive           cream lettering on olive
#   title colour    the spine is printed in the colour its title names ("The Deep
#                   Blue Good-by" is blue), paperbacks; the colour words it knows
#                   are COLOUR_WORDS in library.py
#   blackletter     off-white blackletter (UnifrakturMaguntia) on black
